# Codebusters – Sprint 1 (P-01)

Widok **Landing Page** z tłumaczeniami (PL/EN) w Next.js.

## Tech stack

- **Next.js 16**
- **Tailwind CSS v4**
- **next-intl**
- **react-lite-youtube-embed**
- **pnpm**

## Jak uruchomić

```bash
pnpm install
pnpm dev

```

## Routing

- **`/`** i **`/landing`** - ten sam widok.
- **`/pl/landing`**, **`/en/landing`** - wersje językowe.
